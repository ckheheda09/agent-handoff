安装多端 Agent 插件

先登记设备并下载专用凭证。安装器支持选择 DeepSeek Harness、Hermes、ChatGPT 桌面、Codex Linux，配置中转地址、CA 证书和工作目录。

下载本服务 CA · 下载安装包 · 查看安装说明 · 四宿主使用指南
需要 Node.js 22.18+。将命令中的证书路径换成本机路径。DSH / Hermes 用 /relay，Codex Linux 用 $relay；ChatGPT 桌面选择“接力 · ChatGPT”技能，普通聊天需连接安全隧道。安装后按指南重载并验证。MCP 连接后每 30 秒上报心跳；心跳不代表任务已接受或完成。
远端会话库与一句话接力
发送端说“总结当前会话并上传。”；接收端说“查看远端会话。”，按标题选择后继续，无需先指定设备。查看会话库指南
两端安装新版插件并连接后，发送端说“接力到办公室电脑。”，接收端说“接力。”。设备名称用你在后台设置的名称；有多个 Agent 或待办时再选择。
发送端 Agent 整理当前任务的上下文和必要文件；插件自动发现路由、传输、查收、解密和校验。MCP 连接期间，每 10 秒检查新交接并请求系统提醒；重复交接只提醒一次。
需要本地客户端 0.6.0，旧客户端请使用原 profile 重跑安装并重启宿主；无需更新凭证。实际提醒依赖桌面和通知权限；宿主退出后不检查，也不会自动启动模型。完整原始对话需导出后随文件发送。
